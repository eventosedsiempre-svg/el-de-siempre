📊 Registro automático en Google Sheets
Cada usuario que se registra queda guardado en esta planilla y también en el panel de abajo.
→ Ver mi planilla de Google Sheets

Para activar el guardado automático en Sheets:
1. Abrí script.google.com → Nuevo proyecto → pegá el código de abajo
2. Reemplazá TU_SPREADSHEET_ID con el ID de tu planilla
3. Implementar → Como aplicación web → Cualquier usuario → copiá la URL
4. En este archivo buscá SHEETS_WEBHOOK_URL y pegá la URL
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  const sheet = SpreadsheetApp
    .openById('TU_SPREADSHEET_ID')
    .getSheetByName('Usuarios');
  sheet.appendRow([d.nombre, d.apellido,
    d.email, d.telefono, d.fecha]);
  return ContentService.createTextOutput('ok');
}
